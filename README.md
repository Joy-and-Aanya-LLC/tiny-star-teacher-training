# Tiny Star Teacher Training Course

The self-paced training for Tiny Star teacher candidates: Before the Program Starts, Lessons 1–8, the Final Exam, and booking a classroom demo.

**Course link:** https://joy-and-aanya-llc.github.io/tiny-star-teacher-training/

- `index.html`: the course app
- `course.js`: lesson content and exam questions
- `img/`, `video/`, `scripts/`: slides, videos, and printable script PDFs

Registrations, lesson progress, and exam results go to the Google Sheet "Tiny Star Teacher Candidates" (set `SHEET_URL` in index.html).
